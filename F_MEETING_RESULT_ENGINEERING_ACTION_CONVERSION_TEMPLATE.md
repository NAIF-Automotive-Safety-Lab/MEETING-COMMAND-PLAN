# MEETING RESULT → ENGINEERING ACTION CONVERSION TEMPLATE

| Field | Required entry |
|---|---|
| Meeting ID | Unique meeting reference |
| Organization | Exact organization name |
| Contact | Exact contact name/title |
| Date | Meeting date |
| Source | Meeting minutes / email / approved note |
| Meeting Result | Factual statement only |
| Technical Scope | What the organization explicitly said it can do |
| Required Evidence | What the organization explicitly requested |
| Entry Criteria | Explicit start conditions |
| Commercial Structure | Explicitly offered / accepted structure |
| NDA Trigger | Exact disclosure boundary stated |
| Engineering Action | Concrete next engineering action |
| Deliverable | Exact output |
| Acceptance Criterion | Objective closure criterion |
| Evidence Requirement | Artifact proving completion |
| Owner | Named owner |
| Due Date | Agreed date |
| Status | OPEN / PENDING HUMAN RESPONSE / AGREED / REJECTED / BLOCKED |
| Assumptions | Every unresolved assumption |
| Confidentiality | L1 / NDA / Restricted |
| Authority Note | No commercial or technical commitment unless documented |

## Conversion rule

**Meeting statement → Technical Scope → Required Evidence → Entry Criteria → Commercial Structure → NDA Trigger → Engineering Action → Deliverable → Acceptance Criterion → Evidence Requirement → Owner → Due Date**

Any field not supported by the meeting record must be recorded as **UNKNOWN**, **OPEN**, or **PENDING HUMAN RESPONSE**.
