# MASTER TIMED AGENDA — TECHNICAL QUALIFICATION MEETING

**Total target:** 45 minutes  
**Hard stop:** 45 minutes unless both parties explicitly extend.

| Time | Section | Primary Speaker | Objective |
|---:|---|---|---|
| 0–3 | OPEN / OBJECTIVE | Naif | Establish purpose and non-confidential boundary |
| 3–8 | PROBLEM + WHY IT MATTERS | John | Establish coupled engineering problem |
| 8–13 | T-OCS FUNCTION + ARCHITECTURE | John | Explain functional hypothesis only |
| 13–16 | EVIDENCE BOUNDARY | John | State what is controlled vs open |
| 16–22 | COMPANY RESPONSE / CAPABILITY | Company | Identify actual scope offered |
| 22–27 | C1 — TECHNICAL SCOPE | John | Define candidate work |
| 27–31 | C2 — REQUIRED EVIDENCE | John | Capture entry evidence |
| 31–34 | C3 — ENTRY CRITERIA | John + Company | Establish conditions |
| 34–37 | C4 — COMMERCIAL STRUCTURE | Naif | Capture actual structure, no assumptions |
| 37–40 | C5 — NDA TRIGGER | Naif + Company | Decide disclosure boundary |
| 40–43 | RED TEAM / FALSIFICATION | John | Surface reasons to stop |
| 43–45 | ACTION / OWNER / DEADLINE | Naif | Close with measurable next step |

**Hard-stop rule:** if a discussion becomes proprietary, exact, or vehicle-specific beyond the approved boundary, pause and record the request as an NDA / restricted disclosure item rather than answering from memory or assumptions.
