# TECHNICAL QUALIFICATION QUESTION TREE

## C1 — Technical Scope
→ What can you actually deliver?
→ Direct vs subcontracted?
→ Named outputs?

## C2 — Required Evidence
→ What data must exist before work starts?
→ What evidence do you require to accept an engineering model / test article?

## C3 — Entry Criteria
→ NDA?
→ Requirements baseline?
→ Model / test article maturity?
→ Approval / authorization?

## C4 — Commercial Structure
→ Paid Engineering? Deferred? Co-development? Sponsorship? Investment?
→ Which option is actually available?
→ What constitutes deliverable acceptance?

## C5 — NDA Trigger
→ What is L1?
→ What triggers NDA?
→ What remains restricted after NDA?

### Branch rule
If answer is not supported by the meeting record → PENDING HUMAN RESPONSE.
If a commitment is discussed but not documented → NOT ESTABLISHED.
If technical scope expands beyond agreed scope → OPEN / CHANGE CONTROL REQUIRED.
