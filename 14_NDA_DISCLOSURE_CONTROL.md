# NDA / DISCLOSURE CONTROL

## L1 allowed
High-level problem, functional architecture, development path, current stage, evidence discipline, intended validation path, scoped partnership ask.

## NDA trigger
Any request for controlled technical information beyond L1, including proprietary mechanism, exact dimensions, CAD/STEP, detailed force/energy assumptions, patent-sensitive implementation details, or internal evidence files.

## Restricted even after NDA unless explicitly approved
Internal audit/gap files, full engineering completion work order, confidential third-party information, unapproved source material, and any disclosure not approved by project authority.

## Stop conditions
- request for unsupported performance claim
- request for exact unapproved geometry
- request for customer / partner / funding status not documented
- request to treat model result as physical proof
- request to bypass NDA or disclosure authority
