# NDA / DISCLOSURE CONTROL

## L1 — permissible
- Problem definition
- High-level functional concept
- Functional architecture
- Development path
- Current engineering stage
- Evidence discipline
- Intended validation path
- Bounded engagement ask

## NDA trigger
Pause and request NDA / controlled disclosure when the counterpart asks for:
- proprietary mechanism;
- exact dimensions;
- CAD / STEP;
- detailed force / energy assumptions;
- patent-sensitive implementation;
- internal audit / evidence-gap files;
- full internal engineering work order;
- confidential third-party information.

## After NDA
NDA does **not** automatically authorize every file. Internal audits, confidential third-party data, unapproved sources, and material outside the approved disclosure boundary remain restricted unless explicitly released.

## Commercial rule
Interest ≠ commitment. Discussion ≠ authorization. Proposal ≠ contract.
