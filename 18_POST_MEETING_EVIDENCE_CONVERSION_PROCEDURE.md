# POST-MEETING EVIDENCE CONVERSION PROCEDURE

1. Lock the source record: minutes, email, approved notes.
2. Extract each factual statement into Meeting Result.
3. Convert into Technical Scope.
4. Record Required Evidence exactly as stated.
5. Record Entry Criteria exactly as stated.
6. Record Commercial Structure only when explicitly offered / accepted.
7. Record NDA Trigger.
8. Create Engineering Action.
9. Define Deliverable.
10. Define Acceptance Criterion.
11. Define Evidence Requirement.
12. Assign one accountable Owner.
13. Assign one Due Date.
14. Assign status: OPEN / PENDING HUMAN RESPONSE / AGREED / REJECTED / BLOCKED.
15. Hash the source record and conversion artifact.

No inferred commitment is promoted to project fact.
