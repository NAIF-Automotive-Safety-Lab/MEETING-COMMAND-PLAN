# PROBLEM-SOLVING WORKSHOP SCENARIOS

## Requirement Conflict
Problem → competing requirement statements
Hypotheses → source drift / interpretation drift
Constraints → authority + frozen baseline
Alternatives → preserve both interpretations
Evidence Needed → controlled source / decision record
Falsification Test → reproduce each requirement from source
Decision Criteria → authority-resolved wording
Owner / Deadline → meeting closeout

## Packaging / Interface Conflict
Problem → geometry / package conflict
Hypotheses → vehicle boundary vs seat geometry vs clearance
Constraints → no invented vehicle coordinates
Alternatives → working-copy proposal only
Evidence Needed → vehicle package + inspection
Falsification Test → measured / controlled clearance review
Decision Criteria → explicit package criterion

## Kinematic Feasibility
Problem → intended motion may conflict with joints / end-stops / surrounding geometry
Hypotheses → joint semantics / interference / insufficient travel
Constraints → no silent coordinate transform
Evidence Needed → joint graph + authoritative geometry
Falsification Test → controlled motion sweep / test

## Load / Energy Uncertainty
Problem → component law unknown
Hypotheses → multiple plausible response laws
Evidence Needed → component characterization
Falsification Test → targeted bench test

## Testability / Correlation Uncertainty
Problem → output cannot be measured or correlated
Hypotheses → sensor / model observability gap
Evidence Needed → instrumentation and model definition
Falsification Test → pre-test observability check
