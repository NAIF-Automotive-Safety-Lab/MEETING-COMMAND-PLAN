# MASTER TIMED AGENDA — 45 MINUTE DEFAULT

| Time | Segment | Owner | Hard stop |
|---|---|---|---|
| 00–03 | Introductions / objectives | Naif | 03 |
| 03–08 | Problem + why it matters | Naif | 08 |
| 08–14 | Functional concept / architecture | Naif | 14 |
| 14–18 | Current stage + evidence boundary | Naif | 18 |
| 18–24 | Intended validation + Phase-1 concept | Technical lead | 24 |
| 24–36 | C1–C5 technical qualification | Meeting lead | 36 |
| 36–41 | Adversarial questions / falsification | Both | 41 |
| 41–44 | Decision / next action / owner / deadline | Both | 44 |
| 44–45 | Confirm minutes + close | Recorder | 45 |

No segment is allowed to consume the closeout time.
