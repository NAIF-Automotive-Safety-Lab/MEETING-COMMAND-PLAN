# TECHNICAL QUALIFICATION QUESTION TREE — C1–C5

## C1 — TECHNICAL SCOPE
Start with: **What exact work can you perform for this problem?**

Probe: Engineering / CAE / FE / CAD / Prototype / Testing / Manufacturing / Co-development.

Required capture: scope, direct vs subcontracted work, named deliverables, technical owner.

## C2 — REQUIRED EVIDENCE
Ask: **What do you need to see before your team will accept technical work?**

Capture exact evidence requested; do not infer from industry convention.

## C3 — ENTRY CRITERIA
Ask: **What conditions must be true before Phase-1 can start?**

Probe: NDA, data package, requirements, test article, model definition, approvals, commercial authorization.

## C4 — COMMERCIAL STRUCTURE
Ask: **How would you structure a bounded engagement?**

Probe: Paid Engineering / Deferred Engineering / Co-development / Sponsorship / Investment.

Ask what is actually offered, what is fixed-price, and what closes the purchased deliverable.

## C5 — NDA TRIGGER
Ask: **What specifically can be reviewed at L1, and what requires NDA?**

Capture what remains restricted after NDA and any access / retention / subcontracting limits.

## Closing conversion

**Response → Scope → Evidence → Entry Criteria → Commercial Structure → NDA Trigger → Engineering Action → Deliverable → Acceptance → Evidence → Owner → Deadline**
