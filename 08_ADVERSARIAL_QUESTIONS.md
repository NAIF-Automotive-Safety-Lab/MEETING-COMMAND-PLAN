# ADVERSARIAL QUESTIONS

1. What would falsify the hypothesis?
2. Which part of the response is currently only a design assumption?
3. What evidence would you refuse to accept as proof?
4. Which input is likely to dominate uncertainty?
5. What is the minimum test that can discriminate competing hypotheses?
6. What happens if the left and right load paths do not share load as intended?
7. What happens if vehicle packaging invalidates the assumed motion envelope?
8. What happens if the state transition occurs too early or too late?
9. Which claims would remain unproven even after a component test?
10. What exact result would stop Phase-2?
